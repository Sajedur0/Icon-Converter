# Changelog

All notable changes to ICO Converter are documented in this file.

The project uses [Semantic Versioning](https://semver.org/), and release dates follow the `YYYY-MM-DD` format.

## [1.0.0] - 2026-11-11

### Added

- Initial stable release of ICO Converter.
- Multi-resolution Windows `.ico` export with selectable `16`, `24`, `32`, `48`, `64`, `128`, `256`, and `512` px frames.
- PNG, APNG, JPG, JPEG, WEBP, BMP, GIF, TIFF, and ICO input support.
- Crop, Contain, and Auto-Trim canvas modes.
- Premultiplied linear-light Lanczos3 resampling with EXIF orientation correction.
- Background image preparation and cached per-mode export frames.
- Transparency-aware main preview and pixel-sized `16`, `24`, and `32` px previews.
- File picker and drag-and-drop image import.
- Exact output-size estimation and export status details.
- Minimal light interface with soft shadows and refined typography.
- Bundled application icon in the native window, header, and About dialog.
- About dialog with application version, author, output, engine, license, and project link.
- `Ctrl+O`, `Ctrl+Enter`, and `Esc` keyboard shortcuts.
- Automated Windows executable releases for version tags.
- Apache License 2.0 and bundled Inter font license documentation.
